Patch Notes

March 20, 2026

  • Musical (quater-note) clock BPM setting added.
  • MIDI clock sync added.

March 13, 2026

  • Improved per-timbre UI for MIDI input zone selection. It's much more compact and now displays conventional note names instead of MIDI note numbers.
  • Separated channel pressure and poly aftertouch in the UI.

March 9, 2026

  • Added per-voice MIDI channel selection.

March 7, 2026

  • Improved UI for choosing modulation CCs.

March 6, 2026

  • Support for MPE configuration messages.
  • Fixed implementation of MPE sustain/sostenuto.
  • Added "Aftertouch" emitter parameter. This option allows expressive control of emitter volume via MIDI poly aftertouch or MPE channel pressure.

Feb 21, 2026

  • Two pitch bend algorithms are now available. Normal pitch bends, which are applied only at particle creation--after which the particle maintains its pitch. And GPU pitch bends, which are applied continuously to existing particles. Note that the GPU pitch bend will generate distortion, especially at low pitches.
